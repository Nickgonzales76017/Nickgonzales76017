I build native software, websites, integrations and practical applications for businesses and the people operating them. That means working with systems already in place—ERP, WordPress, SQL, APIs, documents, media, and increasingly agent-facing tools—rather than replacing them just to add another layer.

**Aurekai** is the product and delivery work. **Bonfÿre** is the underlying native and semantic software: work, identity, permissions, data, effects, evidence, and how one result reaches another system.
